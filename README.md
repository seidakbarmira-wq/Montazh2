# Монтаж — телефоннан Reels (Claude Code)

Компьютерсіз, **тек телефонмен** Reels жасайтын шаблон. Claude өзі монтаждайды:
- **Өзіңіз түсірген видео** → қазақша субтитр, зум, плашкалар, бастың артындағы жазу, дыбыс эффектілері, обложка, caption.
- **Тек мәтін** → ИИ дауыс оқиды, экранда графика мен субтитр. 5 стиль: қарапайым, коллаж, tech, алтын, мульт (Мысық Мырза).

Автор: [@i10_aktoty_](https://instagram.com/i10_aktoty_)

## Не керек
- Телефонда **Claude** қосымшасы (Pro немесе одан жоғары жазылым).
- **github.com** аккаунты (тегін).
- 25 МБ-тан үлкен видео үшін — Google Drive.

## Баптау (бір рет, ~10 минут)
1. **Өзіңізге көшіріп алу.** Осы бетте жасыл **«Use this template»** → **«Create a new repository»** → аты, мысалы `montazh` → **Private** → «Create repository».
   (Батырма көрінбесе: браузер мәзірінен «Компьютер нұсқасы / Desktop site» қосыңыз.)
2. **GitHub-ты Claude-қа қосу.** Claude қосымшасы → мәзір → **Code** → жаңа сессия → репозиторий таңдау → GitHub-та «Only select repositories» → өз `montazh` репозиторийіңіз → «Save» → Claude-қа оралу.
3. **Орта.** Сессияның орта баптауынан жаңа орта жасаңыз:
   - Аты: `Монтаж`
   - Желіге рұқсат: **толық** (дауыс моделі мен Drive-тағы видеоны жүктеу үшін)
   - Баптау скрипті: `bash setup.sh`

## Видео монтаждау
1. Видеоны салыңыз: 25 МБ-қа дейін — github.com → репозиторий → `Бастапқы` → «Add file» → «Upload files» → «Commit changes». Үлкені — Google Drive сілтемесі.
2. Claude → Code → жаңа сессия → `montazh` репозиторийі, `Монтаж` ортасы.
3. Жазыңыз: **«Видеоны монтаждап бер»** (немесе **«про монтаж жаса»** — бастың артындағы жазу, әйнек плашкалар).
4. Сұрақтарға жауап беріңіз → **раскадровканы** қараңыз → «ок» немесе правка.
5. Дайын видео мен обложканың сілтемесін аласыз → жүктеп, галереяға сақтайсыз.

## Мәтіннен видео (түсірмей)
Жазыңыз: **«Мына мәтіннен видео жаса: …»**. Стиль сұрасаңыз болады: «коллаж стилінде», «tech стилінде», «алтын стилінде», «мульт стилінде». Дауыстарды тыңдау: «дауыстарды көрсет».

## Папкалар
- `Бастапқы/` — бастапқы видеолар (және өз дауыс файлыңыз)
- `Мәтін/` — мәтіннен видео жоспарлары
- `Раскадровка/` — рендерге дейінгі раскадровкалар
- `Дайын/` — дайын видеолар `_v1, _v2…` және обложкалар
- `менің-талғамым.md` — сіздің ережелеріңіз. Claude правкаларыңызды өзі жазып, келесі видеоларда қолданады.
