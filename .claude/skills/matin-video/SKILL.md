# Мәтіннен видео — @i10_aktoty_

Адам кадрда жоқ. Мәтінді ИИ дауыс оқиды, экранда графика мен субтитр жүреді. Движок: `scripts/matin.py` (шрифт пен субтитр `montazh-kz` скиллінен алынады).
**Раскадровканы пайдаланушы мақұлдамай тұрып рендер жасама.** Бастамас бұрын `менің-талғамым.md` оқы.

```bash
MT="python3 .claude/skills/matin-video/scripts/matin.py"
```
Жоспарлар: `Мәтін/<аты>.json`, раскадровка: `Раскадровка/`, дайын видео: `Дайын/`, жұмыс файлдары: `.matin/` (коммит жасама).

## 1. Мәтінді алу және жетіспейтін деталь
Пайдаланушы мәтін жібереді. `менің-талғамым.md`-де жауабы жоқ, бірақ видеоға әсер ететін нәрсенің бәрін **бір хабарламада, нөмірлеп** сұра — әрқайсысына өз ұсынысыңды қос, пайдаланушы «иә» деп қана жауап бере алсын:
1. Стиль (қарапайым / коллаж / tech / алтын / мульт) — тақырыпқа қарай біреуін ұсын.
2. Видео қайда шығады: таргет немесе Reels.
3. Дауыс: әйел немесе ер (ұсынысыңды айт).
4. Соңғы батырма/шақыру мәтіні («Подробнее» әдепкі).
5. Су белгісіне Instagram аты керек пе (алтын стилінде).
6. Мәтінде түсініксіз немесе қате сөз болса — оны да сұра (мәтінді өзің өзгертпе).
Жауап келмей тұрып жоспарға көшпе.

## 2. Жоспар — `Мәтін/<аты>.json`
Мәтінді **өзгертпе** (пайдаланушы жазғандай қалсын), тек сахналарға бөл:
```json
{
  "name": "telefon-montazh",
  "lang": "kk",
  "voice": {"engine": "piper", "speaker": 0, "speed": 1.05},
  "theme": {"bg1": "#0B1020", "bg2": "#2A1258", "accent": "#FFD60A"},
  "scenes": [
    {"kind": "hook", "text": "... *маңызды* сөз ... ?"},
    {"kind": "say", "big": "ТЕЛЕФОН", "text": "..."},
    {"kind": "step", "num": 1, "title": "Қосымшалар", "text": "Біріншіден, ..."},
    {"kind": "cta", "button": "Подробнее", "card": "Қысқа сұрақ немесе уәде", "text": "... батырмасын басыңыз!"}
  ]
}
```
Сахна түрлері:
- `hook` — бірінші сөйлем. Экранда үлкен мәтін, сөздер айтылған сайын шығады. 1 ғана, ең басында.
- `say` — қарапайым сөйлем: ортада субтитр, артында үлкен контур сөз (`big`, КАПСПЕН, ≤ 10 әріп — сөйлемнің түйіні).
- `step` — тізім/қадам («Біріншіден…»): үлкен нөмір + `title` (1–2 сөз) + субтитр.
- `cta` — соңғы шақыру: карточка (`card` — ≤ 8 сөз), жыпылықтайтын батырма (`button`), төмен көрсеткі. Дауыс `text`-ті толық оқиды.

Ережелер: бір сахна = 1–2 сөйлем; 3–6 маңызды сөзді `*жұлдызшамен*` белгіле (бүкіл видеоға); сандарды сөзбен жаз («5 минут» → «бес минут») — дауыс дұрыс оқиды.

### Түс тақырыптары (`theme`) — әр видеоға әртүрлі таңда
| Аты | bg1 | bg2 | accent | Қашан |
|---|---|---|---|---|
| Түнгі сары | #0B1020 | #2A1258 | #FFD60A | әмбебап, таргет |
| Неон көк | #050B18 | #0A2A4A | #3EC5FF | ИИ, Claude, технология |
| Қызғылт | #1A0B1E | #4A1238 | #FF5C8A | әйелдер аудиториясы |
| Премиум | #0E0E10 | #2B2216 | #E8B04B | курс сату, сенім |
| Жасыл | #07140F | #0F3B2A | #4ADE80 | кеңес, лайфхак |

## 3. Дауысты таңдау (өзің таңдайсың)
1. Сессияда бір рет: `$MT voices` → `Раскадровка/дауыстар.mp4` және `.matin/voices.json` (әр дауыс: әйел/ер, биіктігі). Бұрын жасалған болса — қайта жасама.
2. Таңда:
   - `менің-талғамым.md`-де дауыс жазылса — **соны** ал.
   - Әйелдер аудиториясы, курс, лайфстайл, жұмсақ сенім → **әйел** дауысы; бизнес, техника, қатаң үн → **ер** дауысы.
   - Таргет/жарнама → `speed` 1.05–1.1 (жігерлі); түсіндіру, сабақ → 1.0.
   - Бірнеше видео қатар жасалса — әртүрлі дауыс қолдан (креатив тесті үшін), пайдаланушы басқаша айтпаса.
3. Таңдағаныңды бір жолмен айт: «Әйел дауысын қойдым (Дауыс 2), жылдамдығы 1.05. Басқасын қаласаңыз — `дауыстар.mp4`-ті тыңдап, нөмірін айтыңыз».
4. «Әрқашан осы дауыс» десе — `менің-талғамым.md`-ге жаз.

**ElevenLabs** (ең табиғи дыбыс, ақылы): ортада `ELEVENLABS_API_KEY` болса және пайдаланушы сұраса — `"voice": {"engine": "elevenlabs", "voice_id": "<id>", "model": "eleven_v3"}`. Өз дауысын клондаса — оның voice_id-ін алады. Тек пайдаланушының өз дауысын немесе рұқсаты бар дауысты қолдан.

## 4. Дауыс → раскадровка → мақұлдау
```bash
$MT voice Мәтін/<аты>.json          # дауыс + әр сөздің уақыты
$MT raskadrovka Мәтін/<аты>.json    # -> Раскадровка/<аты>_раскадровка.jpg
```
Раскадровканы **өзің ашып қара**: мәтін сары рамкадан шықпайды, қазақ әріптері дұрыс, үлкен сөз кесілмеген, субтитр тым кішкентай емес. Сосын **міндетті түрде** пайдаланушыға жібер (жіберу құралымен, болмаса GitHub сілтемесімен — CLAUDE.md), қысқаша сипатта да «ок» күт.

## 5. Рендер
```bash
$MT render Мәтін/<аты>.json --max-mb 90    # фонда іске қос; 1 мин видео ≈ 1.5–3 мин
python3 .claude/skills/montazh-kz/scripts/montazh.py frames Дайын/<аты>_vN.mp4
```
Кадрларды тексер, сосын тапсыр. Музыка берсе: жоспарға `"music": "Бастапқы/music.mp3", "music_volume": 0.12`.
Қазақша caption + 5–8 хэштег жаз (таргет болса — қысқа, CTA-мен).

## 6. Правкалар
Мәтін/сахна/түс/дауыс правкасы → `Мәтін/<аты>.json` өзгерт → дауыс өзгерсе `voice` қайта, әйтпесе тек `raskadrovka` → мақұлдау → `render` (жаңа `_vN`). Талғамға қатысты правканы `менің-талғамым.md`-ге жаз.

## 7. Стильдер — қайсысын қашан
Әр стильдің дайын, тексерілген мысалы: `.claude/skills/matin-video/мысалдар/<стиль>.json`. Жаңа видеоны **сол мысалды көшіріп**, мәтін мен карточкаларды өзгертіп жаса — өрістерді ойдан шығарма.

| Стиль | Жоспарда | Не көрінеді | Қашан | Мысал |
|---|---|---|---|---|
| Қарапайым | `theme` түстері ғана | анимациялы фон, үлкен сөз, субтитр, қадамдар | әмбебап, жылдам | `qarapaiym.json` |
| Коллаж | `"theme": {"style": "kollazh"}` | газет-коллаж, қағаз карточкалар, «ransom» әріптер | түсіндіру, қызықты тақырып | `kollazh.json` |
| Tech | `"theme": {"look": "tech", ...}` + `cover` | қараңғы терминал, неон иконкалар | ИИ, Claude, технология | `tech.json` |
| Алтын | `"look": "altyn"` (жоғарғы деңгейде) | қара-көк фон, алтын неон иконкалар, чиптер | курс сату, премиум | `altyn.json` |
| Мульт | бөлек движок `scripts/mult.py` | беж фон, Мысық Мырза кейіпкері, карточкалар | балалық/жеңіл түсіндіру | `mult.json` |

Ерекшеліктері:
- **Коллаж**: әр сахнада `label`, `art` (`type`: phone / cards / folder …), `note` болуы мүмкін — мысалдағы түрлерді ғана қолдан.
- **Алтын**: әр сахнаға `icon` міндетті (мысалдағы иконка аттарынан таңда), `watermark` — оқушының өз Instagram аты.
- **Tech**: обложка бөлек: `$MT oblozhka Мәтін/<аты>.json`.
- **Мульт**: карточкалар (`card`: hook, words, github, repo, starfork, tiles, noprog, connect, cta) GitHub тақырыбына сызылған. Басқа тақырыпқа жаңа карточка керек болса, `mult/page.html` ішіндегі `card()` функциясына қос және раскадровкада міндетті түрде тексер. Ретi:
  ```bash
  $MT voice Мәтін/<аты>.json                                     # дауыс → .matin/<аты>/voice.wav
  python3 .claude/skills/matin-video/scripts/mult.py prep Мәтін/<аты>.json
  python3 .claude/skills/matin-video/scripts/mult.py raskadrovka Мәтін/<аты>.json
  python3 .claude/skills/matin-video/scripts/mult.py render Мәтін/<аты>.json --max-mb 90
  ```
  Жоспардағы `audio` мен `audio_orig` = `.matin/<аты>/voice.wav`.

**Дайын дауыс файлы** (ElevenLabs-тан немесе оқушының өз жазбасы): `Бастапқы/` ішіне сал → `"voice": {"engine": "file", "file": "Бастапқы/<аты>.mp3"}`. Субтитр дауыстағы сөздерге сәйкестендіріледі.
