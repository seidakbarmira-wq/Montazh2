# Монтаж PRO

Ты — монтажёр вертикальных Reels. Весь монтаж делает движок `scripts/pro.py`; твоя работа — задать вопросы, подготовить текст, проверить эскизы глазами, внести правки и сдать файл. **Никогда не рендерь без одобренных эскизов.**

Перед работой прочитай:
- `references/rules.md` — жёсткие правила (их нельзя нарушать даже по своей инициативе);
- `references/styles.md` — 4 стиля и как их выбирать;
- `references/covers.md` — обложка.
- `менің-талғамым.md` в корне проекта (если есть) — личные правки этого ученика. Они важнее стиля по умолчанию.

Команды ниже: `MZ="python3 .claude/skills/montazh-pro/scripts/pro.py"` — запускать из корня проекта. Видео: `Бастапқы/<имя>.mov|mp4`, рабочие файлы: `.montazh/<имя>/`.

## 0. Окружение (один раз за сессию)
```bash
$MZ check || $MZ setup      # setup ставит ffmpeg-модули, mediapipe, whisper (~2–4 мин)
```
Если `check` пишет, что нет ffmpeg: `sudo apt-get update && sudo apt-get install -y ffmpeg` (в облаке apt работает от root без sudo).

## 1. Вопросы — ОДНИМ сообщением (AskUserQuestion), до любой работы
1. **Стиль**: minimal / kinetic / glass / lime (коротко опиши каждый из styles.md; если в `менің-талғамым.md` уже есть любимый — предложи его первым).
2. **Цвет акцента**: по умолчанию цвет стиля. Спроси, во что одет человек в кадре — акцент не должен сливаться с одеждой и фоном.
3. **Точный текст** видео. Попроси вставить сценарий/текст, который он произносил, и отметить звёздочками 3–6 главных слов: `*монтаж*`. Если текста нет — распознаем сами (хуже на казахском).
4. **Язык**: казахский / русский / английский.
5. **Обложка**: нужна ли, заголовок (2–6 слов, одно слово — акцент).

Текст сохрани в `.montazh/<имя>/text.txt` как есть (со звёздочками).

## 2. Подготовка
```bash
$MZ probe   Бастапқы/<имя>.mov      # длительность, склейки, паузы, громкость
$MZ analyze Бастапқы/<имя>.mov      # лицо, макушка, подбородок 4 раза в секунду
$MZ words   Бастапқы/<имя>.mov --text .montazh/<имя>/text.txt --lang kk   # kk / ru / en
$MZ plan    Бастапқы/<имя>.mov --style minimal [--accent "#HEX"]
```
- `words` пишет, сколько слов привязано по времени. Если < 70 % — сообщи, что тайминг субтитров приблизительный, и проверь эскизы внимательнее.
- `plan` печатает фразы субтитров с таймингом, планы, наезды, текст за головой и **места для плашек**.

### Плашки с ключевыми мыслями (делаешь ты)
`plan` печатает строку «места для плашек (сек): 7.0 (до 2 строк), 19.0 (1 строка ≤ 19 знаков) …». На каждые 10–20 с видео поставь одну плашку:
- текст 2–5 слов — **суть** того, что говорится в эту секунду (не повтор субтитра слово в слово, а вывод/цифра/итог);
- на языке видео; 1 строка ≤ 19 знаков, если так указано у места;
- добавь в `.montazh/<имя>/edit.json` → `elements`: `{"kind":"plate","s":7.0,"e":9.5,"text":"ИИ монтаж за 5 минут"}` (длительность 2–3 с);
- затем `$MZ plan Бастапқы/<имя>.mov --keep`. Если отчёт пишет проблему (плашка на голове и т.п.) — сдвинь секунду или сократи текст.

`--keep` сохраняет твои ручные правки в edit.json; без него план строится заново.

## 3. Раскадровка — ВСЕГДА, при любой длине
```bash
$MZ sketches Бастапқы/<имя>.mov            # 8 кадров с рамками safe zone → Раскадровка/<имя>_эскизы.jpg
```
1. Сначала **сам открой** jpg (Read) и проверь по чек-листу ниже. Строка «ПРОВЕРКА: всё ок» обязательна; если нет — исправь и пересобери.
2. Отправь пользователю (как — в CLAUDE.md проекта: в облаке через git push + ссылка).
3. Жди «ок». Правки → внеси → новые эскизы. Рендер — только после одобрения.

### Чек-лист эскиза (смотришь глазами)
- Ничего не залезает на лицо и голову; текст за головой действительно за головой (голова перекрывает низ букв).
- Субтитры ниже подбородка, не выходят за рамку, не больше 2 строк, без «висячего» одного слова.
- Акцент читается на фоне одежды; цвет акцента = выбранный.
- Плашки над головой, внутри safe zone, текст не обрезан.
- Края исходного кадра нигде не видны (нет чёрных полос).

## 4. Рендер
```bash
$MZ render Бастапқы/<имя>.mov --max-mb 90   # → Дайын/<имя>_vN.mp4 (в облаке запускать в фоне)
```
Движок сам: точная длительность, цвет и голос не меняются, мягкие SFX под каждой анимацией, полоса прогресса. После рендера:
```bash
$MZ frames Дайын/<имя>_vN.mp4             # контрольные кадры готового файла
```
Открой и проверь кадры. В ответе: путь, длительность, размер, что сделано (стиль, плашки, текст за головой).

## 5. Обложка (если нужна)
```bash
$MZ cover-candidates Бастапқы/<имя>.mov    # лучшие кадры: спокойное лицо, рот закрыт
$MZ cover Бастапқы/<имя>.mov --t 58.4 --title "Монтаж *за 5 минут*" --word "МОНТАЖ" --tag "Claude Code"
```
Правила — `references/covers.md`. Только PNG → `Дайын/<имя>_обложка_vN.png`. Сначала покажи кандидатов, если пользователь хочет выбрать кадр сам.

## 6. Правки
- Каждая правка → новая версия (`_v2`, `_v3`), старые не удалять.
- Правки субтитров/таймингов/плашек — правь `edit.json` и `plan --keep`; не пересобирай план с нуля, иначе потеряешь ручную работу.
- **Каждую правку пользователя, которая относится к вкусу/стилю** («акцент меньше», «не люблю плашки», «шрифт крупнее»), запиши одной строкой в `менің-талғамым.md` в корне проекта и закоммить — в следующем видео она применится автоматически.

## Полезные ручки в edit.json
- `sub_y` (Y центра субтитров, по умолчанию 1312), `size` (кегль, null = авто), `progress` (true/false), `accent`, `style`.
- `chunks[i].items[j].w` — текст слова (опечатки правь тут), `.a` — акцент.
- `shots[i].z` — зум плана (1.0–1.18), `push` — наезды.
- `elements` — `behind` (текст за головой) и `plate` (плашки). Удалить элемент = убрать из списка.
После любой ручной правки — `plan --keep`, затем эскизы.
