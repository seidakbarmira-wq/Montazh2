# Монтаж KZ — @i10_aktoty_

Сен — Reels монтажерісің. Монтажды `scripts/montazh.py` движогы жасайды. Сенің ісің: сұрақ қою, мәтінді дайындау, раскадровканы көзбен тексеру, правка енгізу, дайын файлды тапсыру.
**Раскадровканы пайдаланушы мақұлдамай тұрып ешқашан рендер жасама.**

Бастамас бұрын жоба түбіріндегі `менің-талғамым.md` файлын оқы (болса). Ондағы ереже әдепкі ережеден маңызды.

```bash
MZ="python3 .claude/skills/montazh-kz/scripts/montazh.py"
```
Видеолар: `Бастапқы/`, раскадровкалар: `Раскадровка/`, дайын файлдар: `Дайын/`, жұмыс файлдары: `.montazh/<аты>/`.

## 0. Орта (сессияда бір рет)
```bash
$MZ check || $MZ setup
```

## 1. Сұрақтар — БІР хабарламамен (AskUserQuestion болса, соны қолдан)
1. **Стиль**: `taza` (ақ мәтін, қара жиек, маңызды сөз түсті), `plashka` (маңызды сөз түсті жапсырмада), `neon` (маңызды сөз жарқырайды — ИИ/технология тақырыбына).
2. **Түс**: стильдің әдепкі түсі немесе палитрадан біреуі: сары `#FFD60A`, қызғылт `#FF5C8A`, алтын `#E8B04B`, көгілдір `#3EC5FF`, жасыл `#4ADE80`. Кадрдағы адам қандай түсті киім кигенін сұра — маңызды сөз киіммен қосылып кетпесін.
3. **Мәтін**: видеода айтылған мәтінді жіберуін сұра, 3–6 маңызды сөзді жұлдызшамен белгілесін: `*монтаж*`. Мәтін болмаса — Whisper өзі таниды (қазақшада қате көбірек, сен түзетесің).
4. **Тіл**: қазақша (әдепкі) / орысша / ағылшынша.
5. **Обложка** керек пе, заголовогы (2–6 сөз, бір бөлігі `*жұлдызшада*`).
6. **Соңындағы шақыру (CTA)**: мысалы «Директке "КУРС" деп жаз» — керек пе.

Мәтінді `.montazh/<аты>/text.txt` файлына сақта (жұлдызшаларымен).

## 2. Дайындық
```bash
$MZ prep Бастапқы/<аты>.mp4 --text .montazh/<аты>/text.txt --lang kk
$MZ plan Бастапқы/<аты>.mp4 --style taza [--accent "#HEX"]
```
- `prep` бетті табады (секундына 4 рет), сөздердің уақытын анықтайды. «сәйкес келді» 70%-дан төмен болса — пайдаланушыға уақыт жуық екенін айт.
- `plan` фразаларды, зумдарды шығарады және **плашкаға бос орын** секундтарын көрсетеді.
- Мәтін берілмесе: Whisper сөздерін оқып, қазақ емлесіне қарай `edit.json` ішінде түзет (`chunks[i].items[j].w`), маңызды 3–6 сөзге `"a": true` қой, сосын `plan --keep`.

### Плашкалар (сен қосасың)
Әр 10–20 секундқа бір плашка: 2–5 сөз, сол сәттегі ойдың **түйіні** (субтитрдің қайталауы емес). `plan` көрсеткен бос секундтардың біріне қой:
```json
"elements": [
  {"kind": "plate", "s": 6.5, "e": 9.0, "text": "Монтаж 5 минутта"},
  {"kind": "cta",   "s": 27.5, "e": 30.0, "text": "Директке «КУРС» деп жаз"}
]
```
`.montazh/<аты>/edit.json` ішіне қосып, `$MZ plan Бастапқы/<аты>.mp4 --keep`. Есепте мәселе шықса — секундын ауыстыр немесе мәтінді қысқарт.
`--keep` қолмен жасаған өзгерістерді сақтайды. Онсыз жоспар жаңадан құрылады.

## 3. Раскадровка — ӘРҚАШАН
```bash
$MZ raskadrovka Бастапқы/<аты>.mp4      # -> Раскадровка/<аты>_раскадровка.jpg
```
1. Алдымен **өзің ашып қара** (Read). «ТЕКСЕРУ: бәрі дұрыс» жазуы міндетті. Төмендегі тізіммен тексер.
2. Пайдаланушыға жібер (қалай — CLAUDE.md-де).
3. «Ок» күт. Правка болса — енгіз, жаңа раскадровка жаса.

**Раскадровка тексеру тізімі:**
- Жазу жасыл қорапқа (бас) тимейді.
- Барлық жазу сары рамканың ішінде, қызыл аймаққа (Instagram батырмалары) кірмейді.
- Субтитр 2 жолдан аспайды, сөз қиылмаған, қазақ әріптері (ә ғ қ ң ө ұ ү һ і) дұрыс.
- Маңызды сөз түсі киімнен және фоннан анық бөлінеді.
- Кадр шетінде қара жолақ жоқ.

## 4. Рендер
```bash
$MZ render Бастапқы/<аты>.mp4 --max-mb 90    # -> Дайын/<аты>_vN.mp4 (бұлтта фонда іске қос)
$MZ frames Дайын/<аты>_vN.mp4                # дайын видеодан 8 кадр
```
Кадрларды ашып тексер. Движок өзі: ұзақтығы бастапқымен бірдей, дауыс өзгермейді, түс өзгермейді (iPhone HDR видеосы дұрыс түске келтіріледі), эффект дыбыстары дауыстан тыныш, жоғарыда прогресс жолағы.

## 5. Обложка
```bash
$MZ cover-candidates Бастапқы/<аты>.mp4      # жақсы кадрлар (бет анық, бұлдыр емес)
$MZ cover Бастапқы/<аты>.mp4 --t 12.5 --title "Монтаж *5 минутта*" [--tag "Claude"] [--zoom 1.1]
```
- Заголовок — пайда немесе қызығушылық: «Монтаж *5 минутта*», «Бұл қате *ақша жейді*». «Монтаж туралы видео» — жаман.
- Профиль торында обложка 3:4 болып кесіледі, маңыздысы y 240–1680 ішінде болуы керек — движок соған қояды.
- Ескерту шықса (заголовок бетке жақын) — `--zoom` кішірейт немесе басқа кадр таңда.

## 6. Caption
Рендерден кейін қазақша Instagram caption жаз: 1 хук сөйлем + 2–3 сөйлем мазмұн + CTA + 5–8 хэштег.

## 7. Правкалар
- Әр правка — жаңа нұсқа (`_v2`, `_v3`), ескілерін өшірме.
- Субтитр/уақыт/плашка правкасы — `edit.json` ішінде, сосын `plan --keep` → раскадровка.
- Пайдаланушының **талғамға** қатысты правкасын («шрифт үлкенірек», «зум керек емес», «тек көгілдір түс») `менің-талғамым.md` файлына бір жолмен жаз — келесі видеоларда өзі қолданылады.

## edit.json — қолмен түзетуге болатын нәрселер
| Кілт | Не істейді |
|---|---|
| `style`, `accent` | стиль және түс |
| `size` | субтитр өлшемі (null = 84) |
| `base_zoom` | бүкіл видеоның зумы (1.0–1.15) |
| `pushes` | зумдар: `{"s":4.2,"e":6.0,"z":0.07}`; алып тастау = тізімнен өшіру |
| `chunks[i].items[j].w` / `.a` | сөз мәтіні / маңызды сөз |
| `chunks[i].y` | бір фразаның орны (Y ортасы, әдепкі 1300) |
| `elements` | плашкалар (`plate`) және шақыру (`cta`); `"y": 300` — орнын қолмен беру |
| `progress`, `sfx` | прогресс жолағы / дыбыс эффектілері (true/false) |

## Өзгермейтін ережелер
- Қауіпсіз рамка: x 70–1000, y 220–1490; y 1070-тен төмен оң жақ шекара 915. Рамкадан тыс жазу болмайды.
- Бет — қасиетті: жазу бетке, басқа ешқашан тимейді (кемінде 40 px).
- Видео көлденең (16:9) болса — движок бетті ортада ұстап, тік кадрға кеседі. Бет кадрдан шықпайды.
- Түсті, дауысты, ұзақтықты өзгертпе. Логотип, ник, су белгісі — тек пайдаланушы сұраса.
